# Offline source-document captures

The three README files in this folder were captured from the pinned GitHub file responses. Their bytes were checked against Git's blob SHA-1, including the `blob <length>\0` header. **All three match the upstream blob hashes exactly.** See CAPTURE_PROVENANCE.json and the commit URLs in sources/SOURCES.md.

These documents preserve their original wording, historical links and instructions. They are source evidence, not new project approval. In particular, an upstream recommendation to correct checksums is not permission to alter the only baseline without a before/after copy, and general RAM-hole guidance is not proof of ownership in this ROM. AGENTS.md and the project validation gates explain those distinctions.

MerpMod/SharpTune source documents retain their original GPL terms. GPL-3.txt is included for reference. Complete source repositories are not included; acquire pinned reference copies with the reviewable fetch script or use the existing local repositories after inventory.
