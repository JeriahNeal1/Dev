Example of Using EC++ Input/Output Libraries

Input/output stream can be used at the initialization of objects istream and ostream if a pointer to an object of the mystrbuf class is used instead of streambuf.

The following shows the hierarchy of these classes. An arrow (->) indicates that hierarchy class references base class.

Example>

 

#include <istream>

#include <ostream>

#include <mystrbuf>

#include <string>

#include <new>

void main(void)

{

 mystrbuf myfin(stdin);

 mystrbuf myfout(stdout);

 istream mycin(&myfin);

 ostream mycout(&myfout);

 

 int i;

 short s;

 long l;

 char c;

 string str;

 

 mycin >> i >> s >> l >> c >> str;

 mycout << "This is EC++ Library." << endl

  << i << s << l << c << str << endl;

 

 return;

}
