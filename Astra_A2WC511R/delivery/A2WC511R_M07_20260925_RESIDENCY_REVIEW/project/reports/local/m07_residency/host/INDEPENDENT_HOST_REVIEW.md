# Root review of supported host observations

Reviewed protocol.py, backends.py and capture.py against the exact six-address nativeA8 request and compiled stock fixtures. No substantive defect found in this bounded review. The client exposes all six unmodified raw bytes, named/addressed values, the complete request/response/echo bytes, UTC and monotonic request/response times, and host-derived predicates. It explicitly distinguishes host observation time from ECU sample age and never infers freshness, physical gear or control eligibility.

One request can be outstanding. Framing, deadline or backend faults terminally fault the client; later results are ignored and no automatic retry occurs. The available transports are finite compiled-fixture replay and an isolated nativeRomRaider encoder/parser child. Exhaustion cannot silently repeat a cached sample. The reviewed profile pins the fixture, unchangedstock ROM and native runtime. It supplies no physical provider backend. These are local reviewed-profile guarantees, not a sandbox for an adversarially replaced Python source or arbitrary user-authored runtime profile.

The capture file is created exclusively, each JSONL record is flushed, and both capture and cleanup errors are recorded. The Java child strips inherited Java-option environment variables locally, is hidden on Windows, and is stopped/closed on completion or failure. Tests cover the relevant timeout, serialization, framing and cleanup behavior. Native parsing uses the installedRomRaider code while retaining the existing side-by-side infrastructure; no installed provider or global definition is replaced.

The fixture records actual unmodified OEM receive/parser/classifier/getter/TX execution under declared RAM/SCI inputs. This establishes reproducible reverse-engineering utility, not vehicle telemetry or physical transport validation. The old A0 full-image attestation remains withdrawn. The tool is a durable supported offline observation/replay service; attaching a physical backend is outside this run and remains explicitly unimplemented.
