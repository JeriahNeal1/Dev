import re
import ida_bytes

def decode_line(ea):
    insn = ida_ua.insn_t()

    size = ida_ua.decode_insn(insn, ea)

    if size <= 0:
        return None

    return idc.generate_disasm_line(
        ea,
        idc.GENDSM_FORCE_CODE
    )


def dump_from(ea, count=30, before=6):
    start = max(0, ea - before)
    start &= ~1

    cur = start

    for _ in range(count):
        line = decode_line(cur)

        marker = ">>" if cur == ea else "  "

        if line:
            print(f"{marker} {cur:08X}: {line}")
        else:
            raw = ida_bytes.get_bytes(cur, 2)
            print(
                f"{marker} {cur:08X}: "
                f"<decode failed> "
                f"{raw.hex(' ') if raw else ''}"
            )

        cur += 2


def scan_r10(start, end):
    all_uses = []
    writes = []

    for ea in range(start & ~1, end & ~1, 2):
        line = decode_line(ea)

        if not line:
            continue

        low = line.lower()

        if re.search(r'\br10\b', low):
            all_uses.append((ea, line))

            # Destination operand appears to be r10.
            if re.search(r',\s*r10(?:\s|$)', low):
                writes.append((ea, line))

    return all_uses, writes

There's another interesting structural discovery here

At 0x249B8 the routine reads:

mov.l #FFFF51B6,r4
mov.b @r4,r0
and   #1,r0
tst   r0,r0

It then chooses between two completely different methods.

One branch uses the r10 value directly and applies the special mappings:

0/6 → invalid/P/N
7   → 1
1–5 → 1–5

The other branch calculates gear using floating-point speed/ratio thresholds and writes gears 1–5 itself.

A strong structural hypothesis is therefore:

FFFF51B6 bit 0

one state → use transmission-provided gear/range code
other     → calculate gear from RPM / speed ratios

That would make sense in Subaru firmware shared between automatic and manual configurations: an automatic can receive an actual transmission gear state, whereas a manual ECU often has to infer gear from RPM and vehicle speed.

I'm marking that as hypothesis, not proven semantics, but the code structure fits very well.
